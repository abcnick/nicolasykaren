# Wedding Invitation Site — Karen & Nicolas

A static wedding invitation website hosted on GitHub Pages at [nicolasykaren.com](https://nicolasykaren.com).

## Features

- Personalized guest invitation links
- Animated envelope card experience
- Live countdown timer to the wedding date
- RSVP form with Google Sheets backend
- Password-protected admin interface for guest management
- Responsive design (mobile-first)

## Tech Stack

- Vanilla HTML, CSS, JavaScript (no frameworks)
- GitHub Pages (hosting)
- Google Sheets + Google Apps Script (data store & API)

## Structure

```
/
├── index.html          # Guest invitation page
├── admin.html          # Admin management interface
├── config.js           # Event configuration
├── css/                # Stylesheets
├── js/                 # JavaScript modules
├── img/                # Images and assets
├── apps-script/        # Google Apps Script source
└── CNAME               # Custom domain config
```
